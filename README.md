# Nauticworx Partner Program

Production frontend for the Nauticworx Partner Program Mapbox directory.

## Production data
- `data/partners.json` — Trusted Partner directory feed.
- `data/network-coverage.json` — aggregated Network Coverage totals.

## Deployment
GitHub Pages should serve the repository root.

## Data separation
Network Coverage is aggregate client/network coverage. Partner Directory data
contains individual Trusted Partner records. These data models remain separate.
